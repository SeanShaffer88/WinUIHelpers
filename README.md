# WinUIHelpers

Planned Windows interface helpers behind a C ABI.

**Status: planned; no implementation published.** This repository does not yet contain a library, C header, build instructions, or release binaries. Dark title bars, Mica, window corners, DPI behavior, and taskbar progress are intended areas of exploration, not implemented features.

The first milestone is one small capability with explicit Windows-version fallbacks, a consumer example, and accessibility/DPI validation. OS and CPU compatibility remain unverified.
